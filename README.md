# Glow Trace

One-finger hyper-casual demo built with three.js (r128, loaded from cdnjs). Single file: `index.html`.

Run: open `index.html` in a browser, or serve the folder (`python3 -m http.server`) and open on a phone.

Levels: draw the line, trace the circle, follow the wave and release inside the ring.
Monetization stubs: interstitial after each level, rewarded ads for lives and hints, coin shop with demo purchases, remove-ads flag, daily gift. All persisted in localStorage under `glowtrace`.
